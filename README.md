# Achadinhos da Rebeca — Landing Page

Página "link na bio" publicada em https://www.achadinhosdarebeca.com.br via GitHub Pages.

- `index.html`: a página (layout editorial). Para trocar um link, edite o `href` do botão correspondente (`data-id="shopee"`, `amazon`, `mercadolivre`, `shein`, `colaedecora`, `tiktok`, `grupo-vip`, `contato`).
- Para esconder um botão, acrescente o atributo `data-pendente` no link.
- `rebeca-banner.jpg`: foto do topo. `rebeca-og.jpg`: imagem da prévia quando o link é compartilhado.
- `logos/`: logos oficiais opcionais dos programas (ver `logos/LEIA-ME.md`).
- `CNAME`: domínio personalizado. Não apagar.
- Botões com `data-cupom="CODIGO"` copiam o cupom ao tocar.
